Play Store Submission Checklist (Remindy)

1) App listing
- [ ] App title in Play Console: Remindy (en-US listing)
- [ ] Short & full description: accurate, no misleading claims
- [ ] Category: Tools

2) Assets
- [ ] App icon uploaded to Play Console matches launcher icon in app
- [ ] Feature graphic and screenshots show real app UI

3) Target audience
- [ ] Set target age: 18+

4) Content rating
- [ ] Complete content rating questionnaire

5) Data safety
- [ ] Fill Data safety form using DATA_SAFETY.md guidance
- [ ] Add privacy policy URL: https://github.com/Chokkhapat-Meechok/Remindy-App/blob/main/privacy-policy.md

6) Ads
- [ ] Advertising declaration: set correctly in Play Console

7) Full-screen intents & permissions
- [ ] `USE_FULL_SCREEN_INTENT` permission added (done in AndroidManifest)
- [ ] Ensure notification code uses full-screen intent only for critical events

8) Build & release
- [ ] Build an Android App Bundle (.aab) with correct versionName/versionCode
- [ ] Sign with release key and upload to Play Console

9) Final checks
- [ ] Test install on device: verify launcher icon and app name match listing
- [ ] Verify privacy policy URL is publicly accessible

Use this checklist when preparing the Play Console submission. I can help complete any step you pick.
